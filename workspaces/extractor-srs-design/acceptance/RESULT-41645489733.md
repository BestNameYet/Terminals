## Independent audit implementation

[verify-live-export.js](verify-live-export.js) is an independently callable audit under the authorized extractor design workspace. It reads the existing committed output and optional final-attestation JSON, without fetching the share URL, modifying output files, or printing conversation text.

The auditor checks **all ten** of the following:

1. Exact eight-file output list, approved run-scoped directory and absence of symlinked file or path components.
2. Receipt schema, content hashes and byte lengths for all six receipt-covered files.
3. Every source-linear record against the full decoded raw conversation array, including index, raw node, ID, classification and derived text.
4. Selected-branch reconstruction directly from the raw mapping and current_node parent graph, with cycle/missing-node safeguards.
5. Role/channel/text sequence and counts against the selected-visible conversation JSON.
6. Exact Markdown regeneration from the independently reconstructed selected-visible messages.
7. Diagnostic counts against the independently counted linear, ancestry and selected-visible records.
8. Precommit execution document has the expected stage, run identity and no premature publication SHA.
9. Byte-for-byte comparison of all eight tracked Git files against filesystem copies.
10. Final attestation: VERIFIED status, same run, published commit ancestry, eight paths, byte lengths and SHA-256 values. GitHub's remote compare API handles shallow-checkout ancestry verification.
