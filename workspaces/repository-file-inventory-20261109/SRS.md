# SRS — Repository source-file inventory (INV-01/INV-02)
Version: 1.0.0. Source: Tasks/User Prompt Task Queue/user-prompt-task-1794196167.json.
This one-repository-at-a-time utility lists all branch and tag source trees for eligible BestNameYet repositories and records every YAML, JavaScript, HTML, and Python Git blob with path, byte size, Git object SHA, and last file-specific commit SHA and timestamp. Every branch/tag is enumerated with pagination, and truncated recursive Git trees are exhaustively expanded.
The utility requires a completed accessible-repository census and verifies that all earlier repositories in the census order were completed. Output is one CSV file, one machine-readable JSON table, and a verification record per repository. Those and a central progress file are committed atomically, then independently read back byte-for-byte. Any API, history, size, validation, or publication failure must block completion; the next repository may not begin until its predecessor is verified. Expression extraction is explicitly excluded and not to be executed during INV-01/INV-02. Uninstalled private repositories are outside the accessible census and must remain a disclosed limitation. Inputs: exactly one validated repository short name from census. Command: python3 workspaces/repository-file-inventory-20261109/scan-one.py <shortname>.
