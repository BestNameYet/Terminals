# Default-branch-only repository source inventory (revision 2.0)

The task is to census every accessible BestNameYet repository pushed within the preceding six months, then inventory each active repository **only on its default branch**, one complete repository at a time. Other branches and tags are explicitly excluded by the user's later instruction. The file inventory covers YAML, JavaScript, HTML, and Python source files, including recognized variant extensions. It records full relative path, byte size, last file-specific commit date and SHA, source revision SHA, and source URL. A separate, verified table must be written for the current repository before any subsequent repository is scanned. The original all-refs file tables are superseded, not valid outputs of this revised task. Git source histories are read via a bare, single-branch checkout; no per-file GitHub commit API requests. Each repository's pinned default branch head, Git tree, and row reconciliation are verified. Expression search is expressly deferred to the user's next instruction. A repository with a failed or incomplete inventory blocks advancement.

The separately documented accessibility limit remains: the GitHub App can only enumerate public repositories and installed private repositories; other account-private repositories may be invisible.
